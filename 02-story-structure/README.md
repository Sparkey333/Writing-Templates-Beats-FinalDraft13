# 02 — Story Structure Frameworks

The universal beat‑sheet frameworks. These are **spines** — pick one (or layer two) to
give any story a shape. They're medium‑agnostic: they work for screenplays, novels, comics,
and games.

## How they relate (they're mostly the same skeleton)

Most Western frameworks are re‑slicings of the same underlying shape. Rough alignment:

| Position | 3‑Act | Save the Cat | Hero's Journey (Vogler) | Story Circle | 7‑Point |
|---|---|---|---|---|---|
| ~0% | Setup | Opening Image / Set‑Up | Ordinary World | You / Need | Hook |
| ~10–12% | Inciting Incident | Catalyst | Call to Adventure | — | — |
| ~25% | Plot Point 1 | Break into Two | Crossing the Threshold | Go | Plot Turn 1 |
| ~50% | Midpoint | Midpoint | Ordeal / Reward | Find | Midpoint |
| ~75% | Plot Point 2 | All Is Lost | Road Back | Take | Plot Turn 2 |
| ~90–100% | Climax → Resolution | Finale / Final Image | Resurrection → Return | Return → Change | Resolution |

**Practical tip:** don't stack more than two. A common, powerful combo is **Three‑Act (the
container) + Save the Cat (the 15 beats inside it)**, or **Story Circle (for the character's
inner arc) laid over Three‑Act (for the plot)**.

**Eastern alternative:** [Kishōtenketsu](./kishotenketsu.md) is *not* on this grid — it builds
on a twist/reframe rather than escalating conflict, and is worth knowing precisely because it
breaks the mold.
