# The Story Grid — Five Commandments of Storytelling

> Every unit of story that works — the whole novel, an act, a scene — obeys the same five
> commandments. — **Shawn Coyne**, *The Story Grid* (2015)

Coyne (a veteran editor) built an editing system. Its most portable tool is the **Five
Commandments**: a checklist that a *global story*, each *act*, each *sequence*, and each
individual *scene* must all satisfy. It's how you "unit‑test" your story at every zoom level.

## When to use it
- Revision & diagnosis: "why does this scene feel flat?" Run the five commandments on it.
- Verifying that small units (scenes) ladder up into the big unit (the global story).

## The Five Commandments (apply to every unit of story)
1. **Inciting Incident** — the event that knocks the unit's protagonist out of balance
   (causal — "because X happened" — or coincidental).
2. **Progressive Complication / Turning Point** — escalating trouble, culminating in the
   **turning point**: new information (an action or a revelation) that changes everything.
3. **Crisis** — the unit forces a hard question, a **best‑bad‑choice** (two negatives) or an
   **irreconcilable‑goods** (two positives) dilemma.
4. **Climax** — the character *answers* the crisis question by taking an action.
5. **Resolution** — the fallout of that action; the new state that sets up the next unit.

## The zoom levels (the "grid")
- **Global** — the whole book has one big set of five commandments (its Global Inciting
  Incident, Global Crisis, Global Climax…).
- **Act / Quadrant** — each of the four quarters has its own five.
- **Sequence** — each cluster of scenes.
- **Scene** — *every scene* has its own five. A scene that doesn't turn (no value shift from
  its beginning to end) is a scene to cut or fix.

## The "value shift" test (scene level)
Every working scene turns a **value** from one pole to its opposite (life→death,
love→hate, freedom→slavery, ignorance→knowledge). Write the value at the top of the scene and
at the bottom. If they're the same, the scene is inert.

## Blank template
```text
UNIT (global / act / scene): ________     VALUE AT STAKE: ____ → ____
1. INCITING INCIDENT —
2. PROGRESSIVE COMPLICATIONS → TURNING POINT (action or revelation?) —
3. CRISIS (best-bad-choice / irreconcilable-goods?) —
4. CLIMAX (the choice acted on) —
5. RESOLUTION (new state) —
CHECK: Did a value shift pole‑to‑pole? Does the Resolution feed the next unit?
```
