# Beat Sheets — Structural Analyses of Produced Films

These are **original structural breakdowns** — our own analysis and commentary describing
each film's plot beats and craft technique in our own words, mapped against the frameworks in
[`../../02-story-structure/`](../../02-story-structure/). They are written for study, the way
a film‑school lecture or a published "beat sheet breakdown" article would be.

**They are not the screenplays.** For the actual scripts, see the legal sources linked in
each file and in [`../../LEGAL-AND-SOURCES.md`](../../LEGAL-AND-SOURCES.md). Read the real
script side‑by‑side with these beat sheets — that combination (primary text + structural
map) is the most effective way to actually absorb a technique.
