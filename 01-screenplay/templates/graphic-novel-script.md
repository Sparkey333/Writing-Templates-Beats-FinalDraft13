# Graphic Novel / Comic Book Script Template

Comic scripting describes **panels on a page**, not continuous time — the reader controls
pacing by how they read a page, unlike film's fixed timing. Final Draft 13's Graphic
Novel/Comic template follows the "full script" convention below (there's also a looser
"Marvel method" — plot‑first, script‑after — noted at the end).

## Format basics
- Organized by **PAGE**, then **PANEL** within the page.
- Each panel gets: an **image description** (what's drawn) and **dialogue/captions** tagged
  to that panel.
- Page count *is* pacing — a decompressed page (1 panel) reads slow; a dense page (8 panels)
  reads fast/chaotic. Choose panel count deliberately.
- **Captions** = narration; **balloons** = speech; **thought balloons** (rare in modern
  comics) = interior monologue.

## Template
```text
TITLE — Issue #__ — "Chapter/Episode Title"
Writer: __________  Artist: __________  Letterer: __________

PAGE ONE (3 panels)

PANEL 1
  << Image description: what the artist draws. Be specific about composition/angle only
  when it matters to story (a reveal, a scale contrast); otherwise trust the artist. >>
  CAPTION: << Narration, if any. >>
  SARAH: << Dialogue, if any. >>

PANEL 2
  << Image description. >>
  SARAH (CONT'D): << Dialogue. >>

PANEL 3 (the page-turn panel — make it a hook)
  << Image description. Page-turn panels should end on a question, reveal, or cliffhanger
  to pull the reader to PAGE TWO. >>
  MARCUS: << Dialogue. >>

PAGE TWO (__ panels)
...
```

## Panel & page craft
- **The page-turn is a beat.** The last panel on a right-hand page is a mini cliffhanger —
  it's the comic equivalent of an act break.
- **Splash page** (one full-page panel) = reserve for a genuine "moment" (a reveal, an
  establishing shot of a new world, an emotional gut-punch) — overuse kills its impact.
  This is very close to a shōnen [transformation beat](../../06-genre-templates/toonami-shonen-powerup-arc.md)
  — many manga spend a full spread on a power-up reveal for exactly this reason.
- **Word count per balloon:** keep dialogue short — a balloon crowding the art fights the
  image. As a rule of thumb, aim under ~35 words per panel across all balloons/captions.
- **Panel-to-panel transitions** (per Scott McCloud, *Understanding Comics*): moment-to-moment,
  action-to-action, subject-to-subject, scene-to-scene, aspect-to-aspect, non-sequitur.
  Vary them; too much action-to-action reads like a flipbook, too much scene-to-scene reads
  disjointed.

## "Marvel method" (alternative workflow)
Writer provides a **plot outline** (beat-by-beat, no panels specified) → artist breaks it
into pages/panels freely → writer scripts dialogue *after* seeing the art. Faster and more
collaborative, less writer control over pacing. Full script (above) gives the writer more
control; Marvel method leans on artist storytelling instinct.

## Sources
- Scott McCloud, *Understanding Comics* (1993) — panel transition taxonomy.
- Format conventions per standard published comic scripts (Alan Moore, Warren Ellis, and
  others have published example scripts widely referenced in the industry).
