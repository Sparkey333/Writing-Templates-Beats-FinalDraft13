# Stage Play Template

Stage format differs from screen format: no sluglines/camera logic, minimal scene breaks
(a play might be one set for a whole act), and stage directions instead of action lines.
Final Draft 13's Stage Play template follows this same convention.

## Format differences from screen
| Element | Screen | Stage |
|---|---|---|
| Location | `INT./EXT. LOCATION - TIME` sluglines per scene | One `SETTING` note per act/scene; the set rarely changes mid-scene |
| Action | "Action lines," present tense, camera-visual only | **Stage directions**, italicized/parenthetical, describe blocking & business |
| Structure | Acts/sequences, often invisible to the audience | **Acts and scenes are audience-visible** (curtain, lights, intermission) |
| Character cue | Left-indented, ALL CAPS | Often **centered**, ALL CAPS, sometimes with a colon: `SARAH:` |
| Time compression | Cuts freely across time/space | Bound by the physical stage; time passes via lighting/blackout, not cuts |

## Template
```text
TITLE OF PLAY
by Your Name

CHARACTERS:
  << NAME >>, << age, one-line description >>
  << NAME >>, << age, one-line description >>

SETTING: << time and place, stated once >>

────────────────────────────────────────
ACT ONE

SCENE 1

SETTING: << the set, described once; note any change from the top >>

AT RISE: << what the audience sees as lights come up — a static tableau >>

SARAH: << Dialogue. >>

(Sarah crosses to the window. A beat.)

MARCUS: << Dialogue. >>

                                                    (Lights fade.)

END OF SCENE 1
────────────────────────────────────────
SCENE 2
...

END OF ACT ONE
────────────────────────────────────────
ACT TWO
...

END OF PLAY
```

## Craft notes specific to stage
- **Everything is dialogue or blocking** — no cutaways, no close‑ups. Information arrives
  through what characters say and do *in real time, in one space*.
  [Truby's 22 steps](../../02-story-structure/truby-22-steps.md) work well here since the
  form rewards tight moral/psychological argument over spectacle.
- **Intermission = a structural act break** — often placed at the [Midpoint](../../02-story-structure/three-act-structure.md)
  or an "All Is Lost" equivalent.
- **Unities** (classical constraint, still useful): consider limiting time, place, and action
  for a tighter play — fewer, bigger sets read as more producible (a practical, not just
  artistic, consideration for stage).
