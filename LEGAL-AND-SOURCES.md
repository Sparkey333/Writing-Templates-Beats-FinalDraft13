# Legal Notes & Sources

This repository is a **study and production toolkit**. It's built to be shared and reused,
so it's careful about the difference between *"material we created"* and *"material other
people own."*

## The short version

- **Templates, questionnaires, and blank beat sheets** in this repo are original works and
  are licensed under Apache‑2.0 (see [`LICENSE`](./LICENSE)). Use them freely.
- **Beat‑sheet analyses of existing films/novels** (e.g., *The Matrix*, *Inception*, *The
  Name of the Wind*) are **original, transformative commentary** — our own structural
  breakdowns written in our own words. Summarizing and analyzing a work's structure for
  education and criticism is a normal, protected use. They contain *analysis*, not the
  works themselves.
- We do **not** host or redistribute **full copyrighted texts** — no complete screenplays,
  no complete novels. When you want the actual script or book, use the **legal links**
  below. This keeps the library shareable without infringing.

## Why we don't paste full scripts/novels here

You asked for "actual copies" of the *Matrix* and *Inception* screenplays and to scrape
copyrighted novels. Two reasons we point to sources instead of copying them in:

1. **Copyright.** Screenplays and novels are protected works. Re‑hosting a complete script
   or book in a public repo is redistribution, which the rights holders don't grant. A repo
   that does that is a takedown target and can't be safely shared — which defeats the point
   of a "compendium to share."
2. **It's not actually the useful part.** For *learning structure and building templates*,
   the leverage is in the **beat map** — where the midpoint lands, how the setup pays off,
   how the reversal works. That's what we extract into reusable form. The full prose/dialogue
   you can read at the legal source while following our beat sheet next to it.

If you have your **own** licensed copies (you bought the screenplay book, you have a legit
PDF), keep them in a local, un‑committed `/private/` folder — add it to `.gitignore` — and
run the beat sheets against them privately. That's yours to do.

## Legal places to read screenplays

| Source | URL | Notes |
|---|---|---|
| Internet Movie Script Database (IMSDb) | https://imsdb.com/ | Large free library; *The Matrix* and *Inception* both listed. |
| Script Slug | https://www.scriptslug.com/ | Clean PDFs of many produced screenplays, incl. *Inception (2010)*. |
| SimplyScripts | https://www.simplyscripts.com/ | Aggregates links to hosted scripts. |
| Drew's Script‑O‑Rama | http://www.script-o-rama.com/ | Long‑running script archive. |
| The Daily Script | https://www.dailyscript.com/ | Curated movie + TV scripts. |
| Studio "For Your Consideration" PDFs | (studio awards sites, seasonal) | Publishers release official PDFs during awards season — the most accurate drafts. |
| Writers Guild Foundation Library | https://www.wgfoundation.org/ | Physical + reference library of scripts. |

> Availability on aggregator sites changes and some hosted copies are unofficial
> transcripts. Prefer official/published editions when accuracy matters.
