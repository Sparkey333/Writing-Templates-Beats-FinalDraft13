# Character Dossier Template

The fill‑in sheet for a major character (Snowflake step 7 / the "character bible"). Do a full
one for each lead and antagonist; a short one for supporting cast. Star ★ the fields that
touch the plot.

```text
NAME:                              ROLE (protagonist/antagonist/ally/mentor/foil):
AGE / APPEARANCE (one vivid detail beats a paragraph):
ONE-LINE ESSENCE (who they are in 8 words):

── THE ENGINE (this drives everything) ────────────────
★ WANT (external, conscious goal):
★ NEED (internal lesson they must learn):
★ FLAW (the lie they believe about themselves/world):
★ GHOST / WOUND (the past event that created the flaw):
★ ARC: positive [ ] · negative [ ] · flat [ ]   → see character-arc-template.md

── VOICE & BEHAVIOR ───────────────────────────────────
[ ] How they speak (rhythm, vocabulary, verbal tic):
[ ] Under pressure they… (fight / flee / freeze / fawn):
[ ] Contradiction (the trait at war with another — makes them human):
[ ] Competence / Proactivity / Sympathy (Sanderson sliders) _/10 _/10 _/10

── RELATIONSHIPS ──────────────────────────────────────
[ ] Who they love / need / resent:
[ ] What each key relationship tests in them:

── BACKSTORY (iceberg — know it, reveal little) ───────
[ ] Where they're from; family; formative events:
[ ] Secret they're hiding:  ⚑
[ ] What they'd never admit even to themselves:

── FUNCTION IN THE STORY ──────────────────────────────
★ Which theme do they embody or argue?
★ First impression (entrance) vs. final impression (exit):
★ If they die/leave, what changes for the plot?

⚑ UNDECIDED (→ focus tab):
  [ ]
```

## Fast version (supporting cast)
```text
NAME — role — want — one flaw — one vivid detail — function in plot.
```
