# Cast & Relationship Map

A one‑page view of who everyone is *to each other*. Ensembles live or die on this. Keeps you
from duplicating roles and shows where dramatic friction is (and isn't).

## Cast roster (fill in)
```text
ROLE                    │ NAME    │ WANT              │ THEME THEY CARRY
Protagonist             │         │                   │
Antagonist              │         │                   │
Mentor                  │         │                   │
Love interest / B-story │         │                   │
Ally 1                  │         │                   │
Ally 2                  │         │                   │
Foil (mirrors hero)     │         │                   │
Threshold guardian      │         │                   │
Trickster / comic       │         │                   │
Shapeshifter/fake ally  │         │                   │
```
*(Roles = Vogler/Campbell archetypes. Not every story needs all; don't cast an actor with no
scenes.)*

## Relationship grid
For each key pair, note the **bond**, the **tension**, and how it **changes**:
```text
PAIR (A ↔ B) │ Bond (what unites) │ Tension (what divides) │ Arc (how it changes)
_____________│____________________│________________________│_____________________
Hero ↔ Antag │                    │                        │
Hero ↔ Love  │                    │                        │
Hero ↔ Mentor│                    │                        │
Hero ↔ Foil  │                    │                        │
Antag ↔ Ally │                    │                        │
```

## Diagram (edit the ASCII, or draw it)
```text
                 [ MENTOR ]
                     │ guides
        rivals       ▼        loves
 [ FOIL ] ────► [ HERO ] ◄───── [ LOVE INTEREST ]
                     │ opposes
                     ▼
                [ ANTAGONIST ] ◄── serves ── [ LIEUTENANT ]
```

## Checks
- [ ] Does every named character **want** something and **push** on someone?
- [ ] Is the **antagonist's** power felt through relationships (not just muscle)?
- [ ] Does the **foil** dramatize the hero's Lie/Truth by contrast?
- [ ] Any two characters interchangeable? → merge or differentiate.
