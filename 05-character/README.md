# 05 — Character

People are the story. These three files build them and wire them together.

| File | For |
|---|---|
| [character-dossier-template.md](./character-dossier-template.md) | The full fill‑in sheet per character (Snowflake step 7) |
| [character-arc-template.md](./character-arc-template.md) | Positive / negative / flat arcs via Lie‑vs‑Truth, Want‑vs‑Need |
| [relationship-and-cast-map.md](./relationship-and-cast-map.md) | Who everyone is to each other; ensemble friction map |

**The one thing to get right:** every major character needs a **Want** (external),
a **Need** (internal), and a **Flaw/Lie** the plot will pressure. That trio is the engine
behind arcs, dialogue, and conflict.
