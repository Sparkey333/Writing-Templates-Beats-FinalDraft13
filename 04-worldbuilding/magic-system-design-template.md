# Magic System Design Template

Built on [Sanderson's Laws](./sanderson-laws-of-magic.md). Fill one per system. If you have
multiple systems, apply the [Third Law](./sanderson-laws-of-magic.md) first and ask whether
you really need more than one.

```text
SYSTEM NAME:
ONE-LINE PITCH:

── ACCESS ─────────────────────────────────
[ ] SOURCE (where does the power come from?):
[ ] WHO can use it (innate? learned? bloodline? bought? chosen?):
[ ] How is it discovered/trained?

── RULES (1st Law: how much does the reader understand?) ──
Position on hard↔soft: |----hard----------soft----|  (mark X)
[ ] What it CAN do (be specific — vague powers can't resolve plots):
    1.
    2.
    3.

── LIMITATIONS (2nd Law: THE most important section) ──
[ ] Hard limits (what it categorically cannot do):
[ ] COST to use (energy, health, sanity, lifespan, material, moral):
[ ] WEAKNESS (how an enemy counters/exploits it):
[ ] Rarity / scarcity (of fuel, practitioners, materials):
[ ] What HAPPENS if you push past the limit?

── CONSEQUENCES (3rd Law: expand what you have) ──
[ ] ECONOMY — who profits? new industries? new poverty?
[ ] WARFARE — how does it change battles, defense, deterrence?
[ ] POLITICS — does it create/destroy power? a mage caste?
[ ] RELIGION — is it holy, profane, worshipped, outlawed?
[ ] CLASS & DAILY LIFE — how does a commoner encounter it?
[ ] TECHNOLOGY — did it replace or fuse with tech?

── STORY INTEGRATION ──────────────────────
★ How does the HERO use it cleverly (within known rules) at the climax?
  (1st-Law audit: the reader must already know every rule used to win.)
★ How does its COST create the hardest choice in the story?
★ One "awesome" moment worth bending a rule for (Zeroth Law):

⚑ UNSURE / TO DECIDE (→ focus tab):
  [ ]
```

## Examples of the pattern
- **Allomancy** (*Mistborn*): burn ingested metals for defined effects; costs the metal,
  telegraphs your moves, each metal = one power. Hard → clever climaxes. (Sanderson)
- **Sympathy** (*Kingkiller*): energy transfer with real thermodynamic cost and "binding"
  rules — see [analysis](../07-reference-analyses/kingkiller-chronicle-structure.md).
- **The One Ring / Gandalf** (*LOTR*): soft — vague power, so magic makes *problems* and
  wonder, never the convenient solution. (Tolkien)
