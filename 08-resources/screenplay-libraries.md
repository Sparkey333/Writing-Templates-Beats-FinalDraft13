# Legal Screenplay Libraries

Where to actually read produced screenplays — for study alongside this repo's
[beat sheets](../01-screenplay/beat-sheets/). See
[`../LEGAL-AND-SOURCES.md`](../LEGAL-AND-SOURCES.md) for the full copyright policy: read,
link, and study freely; don't redistribute full scripts.

| Site | What it is | URL |
|---|---|---|
| **IMSDb** (Internet Movie Script Database) | The largest free HTML script archive; educational use | https://imsdb.com/ |
| **Script Slug** | Clean, modern PDFs, including many awards‑season releases | https://www.scriptslug.com/ |
| **SimplyScripts** | Aggregator linking to movie, TV, anime, and radio scripts | https://www.simplyscripts.com/ |
| **The Daily Script** | Long‑running archive, often multiple drafts per title | https://dailyscript.com/ |
| **Drew's Script‑O‑Rama** | One of the oldest archives (since 1995) | http://www.script-o-rama.com/ |
| **8FLiX** | Hosts studio‑released "For Your Consideration" / awards screenplay PDFs | https://8flix.com/ |
| **Writers Guild Foundation — Shavelson‑Webb Library** | 50,000+ item library, in‑person by appointment, open to the public | https://www.wgfoundation.org/library |
| **WGF "Additional Script Libraries"** | The Foundation's own vetted directory of further sources | https://www.wgfoundation.org/additional-script-libraries |

## Practical notes
- Multiple drafts of a script often circulate; a shooting script or studio FYC PDF is usually
  the most accurate to the finished film.
- IMSDb blocks some automated fetchers (403 on scraper tools) but is fully browser‑accessible
  — open it in a normal browser tab.
- When a print edition exists (many notable screenplays are published as books), it's the
  most citable, stable source for serious study.
