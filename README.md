# Writing Templates, Beats & Story Structure — A Master Compendium

A curated, growing library of **writing templates, story-structure frameworks, beat
sheets, world‑building systems, and worked craft analyses** — drawn from Final Draft 13
Pro and its competitors, from the great teachers of the craft (Blake Snyder, Joseph
Campbell, Dan Harmon, Randy Ingermanson, Brandon Sanderson, J.R.R. Tolkien, John Truby,
and more), and from original templates built here.

The goal is a single, organized, **reusable toolkit** you can pull from to outline,
draft, and analyze your own stories — and a reference you can learn the underlying
patterns from.

> **A note on sources & copyright.** This repo does **not** redistribute full copyrighted
> screenplays or novels (e.g., *The Matrix*, *Inception*, or any published novel). What
> it contains instead are **original beat‑sheet analyses** (transformative commentary and
> structural breakdowns, which is a normal educational/critical use) plus **direct links
> to where those works can be read legally**. See [`LEGAL-AND-SOURCES.md`](./LEGAL-AND-SOURCES.md)
> for the full policy and a citation list.

## How to use it

**Outlining a new project?**
1. Pick a spine from [`02-story-structure/`](./02-story-structure/) (most people start with
   Three‑Act + Save the Cat, or the Story Circle for character‑driven work).
2. If it's a novel, run it through the [Snowflake Method](./03-novel-methods/snowflake-method.md)
   to grow the idea from one sentence to a scene list.
3. Build the world with the [world‑building questionnaire](./04-worldbuilding/worldbuilding-master-questionnaire.md)
   and, if there's magic, [Sanderson's Laws](./04-worldbuilding/sanderson-laws-of-magic.md).
4. Fill a [character dossier](./05-character/character-dossier-template.md) per major player.
5. Writing a script? Grab a [Fountain template](./01-screenplay/templates/) and the
   [formatting spec](./01-screenplay/formatting/screenplay-format-spec.md).

**Learning the craft?** Read the beat sheets in [`07-reference-analyses/`](./07-reference-analyses/)
and [`01-screenplay/beat-sheets/`](./01-screenplay/beat-sheets/) alongside the framework
they follow, and watch the [Sanderson lectures](./08-resources/brandon-sanderson-resources.md).

**Want the fill‑in‑the‑blanks versions?** Every framework file ends with a copy‑pasteable
blank template. Copy it into your own doc and go.

## Conventions

- **Everything is plain Markdown** (or plain‑text `.fountain`), so it's diff‑able,
  greppable, portable, and imports cleanly into Final Draft / WriterDuet / Scrivener.
- Templates use `<< fill this in >>` placeholders and `[ ]` checkboxes so you can copy a
  file and work straight in it.
- Framework files follow one layout: **What it is → When to use it → The beats (with
  positions) → Worked example → Blank template → Sources.**
